# Blog API with Django REST Framework

A simple **Blog API** built with **Django** and **Django REST Framework**. This project allows users to create and interact with blog posts, including comments, replies, likes, and post images.

## Features

- User authentication using Django's default User model  
- CRUD operations for **Posts**  
- Upload and manage **Post Images**  
- Create and manage **Comments** and **Replies**  
- Like system for posts  
- SQLite database for easy setup  

## Tech Stack

- Python  
- Django  
- Django REST Framework (DRF)  
- SQLite
